# Security Policy

## AI-Generated Code Warning

This fork contains code generated by AI (Qwen). It may contain security
vulnerabilities that were not present in the original code. In particular,
the new HTTP REST API (port 8080) is **unauthenticated by design** and must
only be exposed to a trusted local network.

## Reporting a Vulnerability

Please report security issues via GitHub Issues (mark with the "security"
label).

## Before Production Use

1. Run `cargo clippy` and fix all warnings
2. Run `cargo audit` to check for known vulnerabilities
3. Perform manual code review of AI-generated sections
4. Test in an isolated environment
5. Monitor memory usage for leaks
6. Keep port 8080 firewalled from untrusted networks (CORS restricts browser
   origins to local subnets, but the API itself has no auth)
